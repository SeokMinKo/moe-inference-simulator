01 / HARDWARE

GPU를 바꾸면 Roof가 이동

Peak FLOP/s는 수평 천장을, Memory bandwidth는 왼쪽 경사도를 결정합니다. 같은 Workload라면 AI의 x좌표는 그대로이며 Ridge Point = Peak/BW가 달라집니다.

02 / BATCHING

Batch를 키우면 점이 오른쪽으로

Matrix weight를 여러 토큰에서 공유하면 weight 1Byte당 연산량이 증가합니다. 단, 긴 Context에서는 KV Cache 읽기가 늘어 증가 폭이 둔화될 수 있습니다.

03 / INTERPRETATION

Roofline은 실측치가 아닌 상한

Tensor Core 점유율, memory efficiency, kernel fusion, scheduling, MoE expert routing, interconnect 및 cache hit에 따라 실제 추론 속도는 이론 상한보다 낮습니다.

METHODOLOGY
Dense Tensor Core peak, per-device HBM bandwidth. 1 TB = 10¹² bytes. FP8은 지원 GPU에서만 선택 가능.
FP16/BF16 값은 공식 문서의 비희소(non-sparse) 사양을 사용. Attention/KV/Activation 교통량은 분석용 근사 모델.
