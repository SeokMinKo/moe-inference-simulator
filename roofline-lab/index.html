* 모델 전체 Weight + KV(Batch×Context) + 8% 여유 공간을 포함한 근사치. Prefill, MTP, Vision 런타임 및 실제 메모리 단편화는 별도. 용량 초과 시 TPS는 성능 상한 가정치일 뿐, 실행 가능한 수치가 아닙니다.

Why does it move?

AI = operations / transferred bytes
Roof = min(effective TOPS, AI × effective BW / 1000)
Decode TPS ≈ Batch / decode step time
Prefill tok/s ≈ (Batch × prompt tokens) / prefill time

—

Prefill은 전체 입력 토큰 범위에서 Weight를 1회 재사용하는 낙관적 상한 모델이며, Decode는 1개 토큰씩 생성하는 단계입니다. Compute는 Peak 정밀도와 Weight 정밀도가 동일하다고 보장하지 않습니다. FLOPs·TOPS 혼용은 비교를 위한 연산량 추상화이며, 실제 양자화 커널·디퀀트 비용·스케줄러·네트워크·레이턴시는 반영하지 않습니다.
